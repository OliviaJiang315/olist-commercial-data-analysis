## 二、获取方式说明（白名单方式）

本项目数据获取采用课程要求的**白名单方式**中的"官方提供的一次性下载文件"途径，具体操作流程如下：

1. 访问 Kaggle 官方数据集页面：https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. 点击页面提供的 **Download** 按钮，下载 `brazilian-ecommerce.zip` 压缩包
3. 解压压缩包，将其中 11 个 CSV 文件放置于项目 `data/raw/` 目录下
4. 运行 `python scripts/01_load.py` 或 `python run_all.py`，脚本自动读取 CSV 并进行主表规模校验

**全程未使用以下任何爬虫技术：**
- ❌ Scrapy / BeautifulSoup / lxml 等网页解析框架
- ❌ Selenium / Playwright 等浏览器自动化工具
- ❌ requests + 正则表达式等手动页面抓取
- ❌ 任何模拟登录、反爬绕过、IP 代理池等技术

数据获取为**单次手动下载**，不涉及任何自动化网络采集行为，完全符合课程数据获取合规要求。
